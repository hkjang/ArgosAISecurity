# AI 답변의 근거 검사

`argos ask`와 `argos explain`은 AI 답변을 **확인된 사실(AI 분류)·추정·미확인**으로 구분하고, 표시 전에 인용 근거를 검사한다. Anthropic과 Ollama에 같은 검사 규칙을 적용한다. CLI 명령과 `[ai]` 설정은 그대로 사용한다. 기본 조회·제공자 설정은 [AI 조사](FEATURE_AI.md)를 참고한다.

## 확인하는 범위

앱은 선택한 기간·PID로 조회한 파일, 탐지, 프로세스, 대응 결과의 목록을 만든다. 각 인용은 종류·ID·시각·출처가 이 목록과 일치해야 한다. 테이블별로 같은 ID가 존재할 수 있으므로 `files.id:7`과 `responses.id:7`은 다른 근거다.

- 존재하지 않거나 제공되지 않은 ID, 다른 종류, 다른 시각·호스트의 인용은 답변 전체를 거부한다.
- 입력 근거 자체가 선택한 기간·PID를 벗어나거나 건수·누락 표시가 모순되면 모델을 호출하지 않는다.
- 사실과 추정에는 인용이 필요하다. 미확인 항목은 인용 없이 추가 확인 필요 사항을 설명할 수 있다.
- 위협 부재 주장은 구조화된 부재 표시를 요구하고, 미확인 항목에만 허용한다. 이를 사실이나 추정으로 분류하면 답변을 거부한다.
- 조회 건수와 누락 여부는 앱이 직접 출력한다. 하나라도 누락되거나 조회하지 않은 종류가 있으면, 해당 답변으로 선택 기간의 위협 부재를 확인할 수 없다는 안내를 항상 붙인다. 저장된 기록을 전부 조회했어도 센서 미수집까지 배제할 수는 없다.

현재 조사 출처는 **하나의 로컬 이벤트 DB**다. 인용의 출처는 `local`로 고정하며 다른 호스트 표기를 거부한다. DB 파일이 어느 호스트에서 만들어졌는지 인증하거나 여러 호스트의 수집 자료를 대조하는 기능은 아니다. 호스트 이름이나 출처를 문장에 언급하는 것의 진실성도 기계 검사 대상에 포함되지 않는다.

## 응답 처리와 실패

모델에는 JSON으로 세 구분과 인용 목록을 반환하도록 요청한다. 사용자는 검사 후 정리된 한국어 답변을 본다. JSON 형식 불일치, 추가 필드, 누락된 필수 항목, 잘못된 인용, 빈 답변은 오류이며 검증되지 않은 원문으로 대체하지 않는다. 제공자 오류는 상태 코드를 표시하고 서버가 반사한 본문·비밀값을 그대로 출력하지 않는다.

기존 전체 요청 시간 제한과 HTTP 리다이렉트 금지를 유지한다. 요청 본문은 최대 4MiB, 응답은 최대 1MiB다. 응답은 최대 64개 항목, 항목별 최대 32개 인용으로 제한한다. 조회 행 수 상한 외에도 큰 경로·명령행이 요청 제한을 넘으면 기간이나 조회 상한을 줄여야 한다. JSON 응답을 따르지 못하는 로컬 모델은 명확한 형식 오류로 실패한다.

`ThreatExplainer`의 기존 공개 메서드 시그니처는 유지한다. ID 없는 구형 `DetectionContext`/`CopilotContext` 문자열 호출은 별도 `context` 인용으로 구분하며, 확인된 사실을 허용하지 않는다. 이 인용은 DB 이벤트 ID가 아니며 기간·원본 이벤트의 존재를 검증하지 못한다. 실제 CLI의 두 명령은 ID가 있는 기간 조회 경로를 사용한다.

## 한계와 검증

**인용이 실재한다고 문장의 의미까지 정확한 것은 아니다.** 모델이 실제 근거를 잘못 해석하거나, 부재 주장을 다른 종류로 잘못 분류하거나, 본문에 사실과 다른 내용을 적을 수 있다. 검사 대상은 구조화된 인용 필드와 조회 범위이며 자연어의 모든 ID 언급이나 주장의 논리적 타당성을 증명하지 않는다. 답변에 이 한계를 표시하며, 사고 판단에는 원문 근거와 운영 맥락을 확인해야 한다. AI에는 차단·격리·복구를 실행하는 도구나 권한을 제공하지 않는다.

`cargo test -p argos-brain --locked`는 외부 모델 호출 없이 로컬 모의 HTTP 서버로 두 제공자의 요청과 응답 처리를 검사한다. 정상 인용, 존재하지 않는 ID, 종류·호스트·시각 불일치, 기간·PID 밖 입력, 누락 조회의 고정 안내, 부재 단정 거부, 구형 컨텍스트 제한, 형식 오류·제공자 오류·응답 크기 제한을 다룬다. 실제 모델의 한국어 분석 품질이나 악의적 프롬프트에 대한 의미적 저항성을 측정한 결과는 아니다.
