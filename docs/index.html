Core Pillars

엔터프라이즈급 6대 핵심 보안 기능

단순 로그 감시를 넘어 프로세스 차단, 복구, AI 분석까지 일체형으로 제공합니다.

실시간 행위 탐지 (Behavior Scoring)

fanotify 및 notify 기반 파일/프로세스 감시. 슬라이딩 윈도우(10초) 내 변경·삭제·확장자 변경 행위를 0~100점 스케일로 실시간 평가합니다.

argos-sensor + argos-detect

Shannon 엔트로피 암호화 탐지

파일 수정 발생 시 상위 64KB의 엔트로피를 계산(암호화 데이터 ≈ 7.2+). 랜섬웨어가 파일 전체를 암호화하기 직전에 즉각 감지합니다.

Shannon Entropy Engine

해시 검증 무결성 복구 (CAS)

SHA-256 내용 주소 백업 저장소(Content-Addressable Storage)를 운용하여, 변조 전 시점으로 100% 해시 검증 복구를 수행합니다.

argos-recovery (SHA-256)

Ed25519 Cryptographic Policy

서명되지 않은 보안 정책은 즉시 거부됩니다. 공격자에 의한 보안 정책 우회 및 임의 변경을 원천 차단합니다.

argos-policy (Ed25519)

Claude AI Threat Copilot

argos-brain 크레이트를 통해 실제 SQLite Audit Log에만 기반한 AI 위협 분석 요건 보고서를 즉시 작성합니다 (Hallucination 방지).

argos-brain (Claude API)

프로세스 차단 & 네트워크 격리

SIGKILL/SIGSTOP으로 위험 프로세스 즉각 사살 및 iptables 기반 ARGOS_ISOLATE 체인을 생성하여 2차 감염 확산을 방지합니다.

Quick Start

빠른 시작 (Quick Start)

Rust 1.75+ 환경에서 명령 몇 줄로 에이전트와 CLI를 실행할 수 있습니다.

# 1. 워크스페이스 빌드
cargo build --workspace
# 2. 에이전트 데몬 실행 (기본 설정)
cargo run -p argos-agent
# 3. 다른 터미널에서 CLI 상태 및 위협 감시
cargo run -p argos-cli -- status
cargo run -p argos-cli -- threats
# 4. AI Copilot 사고 분석 (ANTHROPIC_API_KEY 설정)
export ANTHROPIC_API_KEY=sk-ant-...
cargo run -p argos-cli -- explain 1
FAQ & AEO

자주 묻는 질문 (FAQ)

Argos AI Security 도입 및 운용에 대한 주요 답변입니다.

Argos는 단순히 알려진 시그니처 패턴만 비교하는 것이 아니라, 실시간 행위 점수(Behavior Scoring)와 Shannon 엔트로피 분석을 결합하여 Zero-day 랜섬웨어도 즉각 감지합니다. 또한 공격으로 훼손된 파일은 SHA-256 기반 내용 주소 백업(CAS)을 통해 공격 이전 시점으로 100% 해시 검증 복구가 가능합니다.
Argos는 안정성을 최우선으로 설계되었습니다. 기본 정책은 auto_block=false(Dry-run 모드)이며, 오탐 방지를 위해 위험 점수가 80점 이상이고 확실한 원인 pid가 식별된 경우에만 차단 조치를 수행합니다. 또한 시스템 핵심 프로세스(pid 0 등)에 대한 시그널 전송은 원천적으로 거부됩니다.
전혀 유출되지 않습니다. argos-brain 크레이트는 실제 파일 내용이 아닌, SQLite 감사 로그에 기록된 파일 이벤트 유형, 변경 비율, 엔트로피 점수 등 메타데이터만을 요약하여 Claude API로 전달합니다 (Hallucination 방지 및 보안 준수).
네, 전체 워크스페이스는 Windows/macOS 환경에서도 컴파일 및 테스트가 지원됩니다. 크로스 플랫폼 파일 센서(notify)가 제공되며, Linux 전용 기능(fanotify, process kill, iptables)은 #[cfg(target_os = "linux")]로 안전하게 격리되어 있습니다.
