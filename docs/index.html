Core Pillars

탐지부터 조사·복구까지

자동 차단은 기본 비활성입니다. 정책을 과거 이벤트로 비교하고 정상본을 검토한 뒤 운영 범위를 넓힐 수 있습니다.

행위·Linux 설정 분석

notify/fanotify와 /proc 관측, 선택한 다중 시간 구간과 Linux 설정 의미를 분석합니다. 별도 경로·마운트 검사는 공백을 표시하고 시험 파일로 DB 수신을 확인합니다.

argos-sensor + argos-detect

내용 표본과 엔트로피

기본 앞부분 64 KiB를 분석하며, 선택 기능으로 읽기 예산을 앞·중간·끝에 나눕니다. 이전 관측과 파일 유형을 비교하지만 파일 전체 검사나 공격 판정을 보증하지는 않습니다.

Shannon Entropy Engine

정상본 복구·사건 보존

정상본 미리보기와 사건 보존, SQLite·PostgreSQL 복구 시험을 지원합니다. 보고서의 계획·백업·필수 검사·나이를 대조하며, 무서명 보고서의 출처 인증과는 구별합니다.

argos-recovery (SHA-256)

서명 정책·사전 검증

서명·버전·유효기간·대상·키 ID를 검사합니다. 저장 이벤트로 정책을 비교하고 승인 예외의 매칭·만료·범위와 예외 제거 영향을 확인합니다.

argos-policy (Ed25519)

근거 기반 AI·증거 패키지

AI 인용을 실제 근거와 대조합니다. 검증한 증거·정상본을 영속 대기열로 전송하고 서명 수신증명을 확인합니다. 서버는 전체·에이전트 한도와 디스크 여유를 검사합니다.

argos-brain (Claude API)

프로세스 차단·네트워크 격리

자동 차단을 켠 Linux 호스트에서 PID·시작 시각·부팅 ID를 확인하고 종료 결과를 기록합니다. 별도 격리 명령은 IPv4/IPv6의 명시적 관리 연결만 허용합니다.

argos-response (Linux)
Interactive CLI

CLI 사용 흐름 살펴보기

설명을 위한 가상 데이터와 요약 예시입니다. 실제 서버에 연결하거나 명령을 실행하지 않으며, 처리 시간·탐지율·복구율의 측정 결과가 아닙니다.

demo@argos:~$ argos --config argos.toml status
[예제 설정을 사용하는 상태 출력 발췌] 센서 : Notify 자동 차단 : 비활성 (탐지 전용) 중앙 서버 : 미연동 (standalone) 생존 신호와 보호 지표는 실제 에이전트 기록에서 확인합니다. 탐지 없음과 감시 중단은 서로 다른 상태입니다.
Rust Workspace

수집·판단·보존을 나눈 구조

대응 판단과 알림 억제를 분리하고 백업·사건 보존·중앙 전송을 별도 작업으로 처리합니다. 실제 운영 처리량은 배포 환경에서 검증해야 합니다.

argos-sensor

notify / fanotify 파일 이벤트와 /proc 신원·UID/GID·capability 관측

argos-detect

센서별 점수·내용 표본·선택적 다중 시간창과 계보 집계

argos-recovery

정상본 판정·미리보기·복구 시험·독립 사건 보존 참조

argos-response

pidfd 신원 확인·종료 결과 감사와 IPv4/IPv6 격리

argos-brain

Anthropic / Ollama 기반 기간별 근거 조회와 AI 설명

argos-policy

서명·버전·기간·대상 검증, 승인 근거를 포함한 새 버전 롤백

Quick Start

v0.4.0 빠른 시작

배포 바이너리: GNU/Linux x86_64, glibc 2.39 이상. 소스 빌드: Rust 1.86 이상.

설치·업그레이드 · AI 제공자·모델 ID 설정

# 1. 릴리즈 파일 두 개를 내려받고 압축 파일 검증
curl -fLO https://github.com/hkjang/ArgosAISecurity/releases/download/v0.4.0/argos-v0.4.0-linux-x86_64-gnu.tar.gz
curl -fLO https://github.com/hkjang/ArgosAISecurity/releases/download/v0.4.0/SHA256SUMS
sha256sum -c SHA256SUMS
# 2. 압축을 풀고 감시·DB·백업 경로 설정 확인
tar -xzf argos-v0.4.0-linux-x86_64-gnu.tar.gz
cd argos-v0.4.0-linux-x86_64-gnu
cp config/argos.example.toml argos.toml
# 3. 자동 차단이 꺼진 예제 설정으로 실행
./bin/argos-agent --config argos.toml
# 4. 다른 터미널의 같은 디렉터리에서 상태 조회
./bin/argos --config argos.toml status

자주 묻는 질문 (FAQ)

Argos AI Security 도입 및 운용에 대한 주요 답변입니다.

탐지·대응 결과와 정상본 무결성 외에 경로 공백, 시험 이벤트 수신, DB 복원 검사, 원격 보관 수신증명과 AI 인용을 확인합니다. 실제 시험 범위는 검증 문서에 기록합니다. 전체 서비스 복구, 운영 탐지율이나 AI 문장의 의미까지 보증하지는 않습니다.
