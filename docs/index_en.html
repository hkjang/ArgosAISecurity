Core Pillars

Detection, investigation and recovery

Automatic blocking is off by default. Compare policies against recorded events and review recovery points before expanding deployment.

Behavior and Linux configuration analysis

Combine notify/fanotify and /proc observations with optional time windows and Linux configuration analysis. Check path and mount gaps separately, and confirm a probe event reaches the database.

argos-sensor + argos-detect

Content samples and entropy

The default reads up to 64 KiB from the beginning. Optional sampling divides a read budget across the beginning, middle and end and compares prior observations and file types. It does not inspect every byte.

Shannon Entropy Engine

Reviewed recovery and incident retention

Preview reviewed backups, retain incident references and run SQLite/PostgreSQL recovery drills. Check report plans, backup bytes, required checks and age; unsigned report provenance is not authenticated.

argos-recovery (SHA-256)

Signed policies and preflight comparison

Check signatures, versions, validity, targets and key IDs. Replay recorded events to compare policies and examine exception matches, expiry, scope and removal impact.

argos-policy (Ed25519)

Evidence-based AI and export

Match AI citations against real records. Queue verified packages and backups for delivery and validate signed receipts. The server checks global and per-agent limits and available disk space.

argos-brain (Claude API)

Process response and network isolation

With blocking enabled on Linux, verify PID, start time and boot ID before termination and record the result. Separate IPv4/IPv6 isolation commands allow only explicit management connections.

Quick Start

Quick start with v0.5.0

Release binaries: GNU/Linux x86_64, glibc 2.39+. Source builds: Rust 1.86+.

Installation and upgrade · Configure an AI provider and explicit model ID

# 1. Download both release files and verify the archive
curl -fLO https://github.com/hkjang/ArgosAISecurity/releases/download/v0.5.0/argos-v0.5.0-linux-x86_64-gnu.tar.gz
curl -fLO https://github.com/hkjang/ArgosAISecurity/releases/download/v0.5.0/SHA256SUMS
sha256sum -c SHA256SUMS
# 2. Extract and configure paths before starting
tar -xzf argos-v0.5.0-linux-x86_64-gnu.tar.gz
cd argos-v0.5.0-linux-x86_64-gnu
cp config/argos.example.toml argos.toml
# 3. Run with automatic blocking disabled
./bin/argos-agent --config argos.toml
# 4. In another terminal, from the same directory
./bin/argos --config argos.toml status

Stored file, detection, process and response evidence goes to the configured provider.
