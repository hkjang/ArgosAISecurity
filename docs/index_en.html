Core Pillars

6 Enterprise-Grade Core Security Features

Goes beyond simple log monitoring to deliver integrated process blocking, recovery, and AI analysis.

Real-Time Behavioral Detection (Behavior Scoring)

fanotify and notify-based file/process monitoring. Evaluates modification, deletion, and extension changes within a sliding window (10s) on a 0-100 scale in real time.

argos-sensor + argos-detect

Shannon Entropy Encryption Detection

Calculates entropy of the first 64KB upon file modification (encrypted data ≈ 7.2+). Instantly detects ransomware just before full-file encryption.

Shannon Entropy Engine

Hash-Verified Integrity Recovery (CAS)

Operates SHA-256 Content-Addressable Storage (CAS) backup to perform 100% hash-verified recovery to pre-tampering state.

argos-recovery (SHA-256)

Ed25519 Cryptographic Policy

Unsigned security policies are immediately rejected. Completely blocks attacker bypass and arbitrary modification of security policies.

argos-policy (Ed25519)

Claude AI Threat Copilot

Instantly generates AI threat analysis reports based solely on actual SQLite Audit Logs via the argos-brain crate (preventing hallucinations).

argos-brain (Claude API)

Process Blocking & Network Isolation

Immediately terminates dangerous processes with SIGKILL/SIGSTOP and creates iptables-based ARGOS_ISOLATE chains to prevent secondary infection spread.

argos-response (Linux)

Quick Start

Quick Start

Run the agent and CLI with just a few commands in a Rust 1.75+ environment.

# 1. Build workspace
cargo build --workspace
# 2. Run agent daemon (default config)
cargo run -p argos-agent
# 3. Monitor CLI status and threats in another terminal
cargo run -p argos-cli -- status
cargo run -p argos-cli -- threats
# 4. AI Copilot incident analysis (set ANTHROPIC_API_KEY)
export ANTHROPIC_API_KEY=sk-ant-...
cargo run -p argos-cli -- explain 1

Frequently Asked Questions (FAQ)

Key answers about deploying and operating Argos AI Security.

Argos goes beyond simply comparing known signature patterns by combining real-time Behavior Scoring with Shannon entropy analysis to instantly detect Zero-day ransomware. Additionally, attack-damaged files can be 100% hash-verified and recovered to pre-attack state via SHA-256 Content-Addressable Storage (CAS) backup.
Argos is designed with stability as the top priority. The default policy is auto_block=false (Dry-run mode), and blocking is only performed when the risk score exceeds 80 and a definitive source pid is identified to prevent false positives. Signal transmission to core system processes (pid 0, etc.) is fundamentally rejected.
Absolutely no leakage occurs. The argos-brain crate sends only metadata summaries from SQLite audit logs — file event types, change rates, entropy scores — to the Claude API, never actual file contents (preventing hallucination and ensuring security compliance).
Yes, the entire workspace supports compilation and testing on Windows/macOS. Cross-platform file sensors (notify) are provided, and Linux-specific features (fanotify, process kill, iptables) are safely isolated with #[cfg(target_os = "linux")].
